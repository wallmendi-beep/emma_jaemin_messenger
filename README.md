# 엠마 · 재민이 · 오빠 로컬 협업방

외부 메신저를 거치지 않고 이 컴퓨터의 `127.0.0.1`에서만 작동하는 3인 협업방입니다. 메시지는 `data/messages.db`에 보존됩니다.

## 실행

`Start Messenger.bat`를 더블클릭합니다. 브라우저가 `http://127.0.0.1:8765`로 열립니다. 창을 닫아도 메시지는 남지만, 자동중계를 계속하려면 실행 창은 켜 두어야 합니다.

처음 설치하거나 컴퓨터를 포맷한 뒤에는 `Install.bat`를 한 번 실행합니다. 자동시험을 통과한 경우 바탕화면에 `엠마 재민이 협업 메신저` 바로가기가 생성됩니다.

## 프로젝트

- 왼쪽의 `+ 새로 만들기`에서 프로젝트 이름을 입력합니다.
- 작업 폴더, Hermes 세션 ID, 재민이 대화 ID는 선택사항입니다.
- 프로젝트마다 메시지, 판단 대기 상태, 연결정보가 분리됩니다.
- 기존 메시지는 업데이트 시 자동으로 `기본 프로젝트`에 보존됩니다.
- 프로젝트를 만들어도 실행 권한은 열리지 않습니다. 모든 프로젝트는 협의 전용으로 시작합니다.

## 협업 원칙

- 공통 안전원칙은 모든 프로젝트에 적용되며 화면에서 보호 상태로 표시됩니다.
- 오른쪽 입력란에 오빠가 직접 추가한 프로젝트 원칙은 즉시 활성화됩니다.
- 대화창에서 “이 내용을 협업 원칙으로 제안해 줘”라고 요청할 수 있습니다.
- 엠마나 재민이가 정리한 원칙은 `제안됨` 상태로 저장되고, 오빠가 `승인 · 적용` 버튼을 눌러야 활성화됩니다.
- 활성 원칙만 다음 AI 협의에 전달됩니다.

## 포맷 후 복원

1. Python, Hermes Agent, Antigravity CLI를 설치합니다.
2. 이 GitHub 저장소를 원하는 폴더에 clone합니다.
3. 저장소의 `Install.bat`를 실행합니다.
4. 바탕화면 바로가기로 메신저를 시작합니다.

`data/messages.db`는 프로젝트명·세션 ID·대화 내용이 들어가는 개인 데이터이므로 GitHub에 올리지 않습니다. 포맷 후 과거 대화까지 복원하려면 이 파일은 별도로 개인 백업해야 합니다.

## 현재 안전범위

- 엠마와 재민이는 협의 전용 모드입니다.
- 재민이는 `agy --mode plan --sandbox`로 실행됩니다.
- 엠마는 Hermes의 `safe` 도구세트로 실행됩니다.
- 파일 수정·명령 실행·실행 완료 주장은 금지됩니다.
- 한 번에 최대 6회만 자동 왕복합니다.
- `USER_DECISION_REQUIRED`가 발생하면 자동협의가 멈춥니다.
- 오빠가 해당 질문에 답변하면 다시 시작합니다.

## 종료

실행 창에서 `Ctrl+C`를 누릅니다.

## 시험

```bash
python -m unittest discover -s tests -v
```

## 구성

- `messenger/store.py` — SQLite 프로젝트·메시지·프로젝트별 일시정지 상태
- `messenger/server.py` — 로컬 HTTP API
- `messenger/bridge.py` — Hermes↔Antigravity 자동중계
- `messenger/launcher.py` — 서버·브리지·브라우저 통합 실행
- `static/index.html` — 오빠가 참여하는 로컬 웹 화면
