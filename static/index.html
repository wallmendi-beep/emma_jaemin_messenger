엠마 · 재민이 메모 우편함

공유 MD를 쓴 뒤 “이 버전을 읽어 주세요” 알림을 남깁니다. 기존 작업 세션이 polling adapter를 연동해야 수신합니다. 새 AI를 실행하거나 열린 터미널에 주입하지 않습니다.

이 서버는 로컬 메타데이터 전달만 담당합니다. 기존 AI 작업자가 내용을 처리하면 AI 제공자 서버로 전송될 수 있습니다.

연결 확인 중

프로젝트 추가
메모 파일을 직접 수정하거나 업로드하지 않습니다. 같은 프로젝트·수신자·경로·해시의 재전송은 중복 등록되지 않습니다.

전달 상태

pending 대기 · claimed 수신권 확보 · read 읽음 확인 · completed 결과 연결 · error 오류

claimed/read 임대 만료는 다음 poll에서 재수신됩니다. 읽음은 작업자의 확인이며 AI 이해를 증명하지 않습니다.
이전 대화 — 읽기 전용 (기존 상태 그대로 보존)
